# Tutorial do Cliente — Como pedir na Marmitas TB

## Boas-vindas

Este guia explica, passo a passo, como realizar um pedido pela Marmitas TB. A página inicial foi organizada para agilizar a escolha: a **marmita do dia** aparece logo na abertura e o botão **Realizar pedido** leva você ao cardápio disponível.

> Os produtos, complementos, horários, preços e modalidades válidas são sempre os exibidos pelo próprio sistema no momento do pedido.

| O que você consegue fazer | Onde começar |
|---|---|
| Escolher a sugestão do dia | Página inicial, no destaque “Marmita do dia” |
| Ver todas as opções disponíveis | Botão **Realizar pedido** ou **Ver cardápio completo** |
| Revisar e alterar itens | Botão **Sacola** |
| Informar entrega ou retirada | Fluxo de finalização da sacola |
| Consultar a situação depois da compra | Link **Acompanhar pedido** no topo |
| Tirar dúvidas de navegação | Botão **Ajuda** no canto da página |

## 1. Abrir o cardápio

Na tela inicial, confira a **Marmita do dia** e clique em **Realizar pedido**. O sistema deslocará você até o cardápio da casa. Também é possível usar o botão **Ver cardápio completo** para chegar ao mesmo local.

O cardápio apresenta categorias e itens disponíveis. Você pode percorrer as opções ou utilizar a busca, quando ela estiver disponível na tela, para encontrar um prato pelo nome.

## 2. Escolher e personalizar sua marmita

Ao encontrar uma opção desejada, abra o item. Alguns pratos possuem escolhas de tamanho, embalagem, acompanhamentos ou observações. As opções obrigatórias precisam ser selecionadas antes de o item entrar na sacola; as opcionais ficam a seu critério.

| Ação | Como proceder |
|---|---|
| Adicionar um prato | Abra o item, selecione as opções apresentadas e confirme a inclusão. |
| Acrescentar observação | Use o campo exibido no próprio item, como “sem cebola”, quando disponível. |
| Escolher um adicional | Volte ao cardápio e abra a categoria correspondente. |
| Alterar quantidade | Use os controles da sacola depois de adicionar o produto. |

Não há necessidade de informar dados pessoais para navegar no cardápio. Use apenas os campos que aparecem durante a finalização e somente se estiver de acordo com o pedido.

## 3. Conferir a sacola

Clique em **Sacola**, no topo da página. Em celular, a barra inferior também mostra o acesso à sacola. Nessa etapa, revise cuidadosamente os itens, personalizações, quantidades, subtotal, taxa aplicável e total exibido.

Se precisar mudar algo, ajuste a quantidade ou remova o item e volte ao cardápio. Quando tudo estiver correto, use a ação de continuar para informar como deseja receber o pedido.

## 4. Escolher entrega ou retirada

O checkout apresenta as modalidades que a operação disponibiliza. Para **entrega**, informe os dados de endereço solicitados pela tela. Para **retirada**, siga a orientação de horário e local exibida pelo sistema.

> Leia cada informação antes de avançar. O sistema só deve ser confirmado quando o resumo do pedido, a modalidade e o total estiverem corretos.

## 5. Finalizar o pedido

Escolha uma das formas de pagamento que aparecem no checkout, revise o resumo final e confirme. A tela de confirmação mostra o código ou a referência necessária para acompanhar o pedido e as orientações seguintes.

O sistema pode apresentar diferentes formas de pagamento conforme a configuração operacional. Não informe senhas, códigos de autenticação, números completos de cartão ou outros dados sensíveis em campos que não sejam o checkout oficial.

## 6. Acompanhar o pedido

Use **Acompanhar pedido**, no topo da página, para abrir a área de consulta. Informe somente o dado solicitado pela tela e verifique a linha do tempo da comanda. Ela indica a evolução do pedido e quaisquer orientações de retirada ou entrega.

| Se você precisa... | Faça isto |
|---|---|
| Confirmar se o pedido foi recebido | Abra o acompanhamento e confira o primeiro status. |
| Saber se está em preparo | Consulte a linha do tempo atualizada. |
| Ver orientações de retirada | Leia as informações exibidas ao lado do status. |
| Começar um novo pedido | Volte à página inicial e abra o cardápio. |

## 7. Usar a Ajuda Marmitas TB

O botão flutuante **Ajuda** abre o **Assistente de pedidos**. Ele explica como navegar, escolher itens, revisar a sacola, finalizar e acompanhar a compra. Também há perguntas rápidas e um link para esta página de tutorial.

O assistente é apenas orientativo. Ele não cria, confirma, altera ou cancela pedidos; não acessa sua comanda e não processa pagamentos. Para sua segurança, não escreva no chat senha, código de acesso, telefone, endereço, e-mail, CPF, dados de pagamento ou identificadores de pedido.

## Referência rápida

| Situação | Caminho recomendado |
|---|---|
| “Quero ver o que tem hoje” | Página inicial → **Realizar pedido** |
| “Quero alterar a quantidade” | **Sacola** → controles do item |
| “Quero receber em casa” | Sacola → continuar → **Entrega** |
| “Vou buscar no balcão” | Sacola → continuar → **Retirada** |
| “Quero saber onde está meu pedido” | **Acompanhar pedido** |
| “Não sei qual botão usar” | **Ajuda** → pergunta sugerida |
