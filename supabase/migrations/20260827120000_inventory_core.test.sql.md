# Verificação SQL — núcleo de estoque

Este roteiro é exclusivamente para a etapa posterior à autorização explícita de migração. Não deve ser executado durante o desenho ou a implementação local, pois cria dados de teste controlados.

## 1. Verificação de esquema

```sql
select table_name
from information_schema.tables
where table_schema = 'public'
  and table_name in ('inventory_items', 'inventory_movements', 'inventory_item_balances')
order by table_name;

select routine_name
from information_schema.routines
where routine_schema = 'public'
  and routine_name in (
    'create_inventory_item',
    'update_inventory_item',
    'set_inventory_item_active',
    'create_inventory_movement'
  )
order by routine_name;
```

## 2. Saldo derivado e auditoria

Depois de criar um insumo de teste e registrar uma entrada seguida de consumo por RPC, consultar apenas as linhas relacionadas aos UUIDs criados na mesma sessão.

```sql
select item_id, balance_quantity, minimum_stock
from public.inventory_item_balances
where item_id = :'item_id'
limit 1;

select action, entity_type, entity_id, metadata
from public.audit_logs
where entity_type = 'inventory_movement'
  and entity_id = :'movement_id'
limit 1;
```

O saldo deverá ser a soma dos deltas. Uma repetição com a mesma `p_idempotency_key` deve devolver o mesmo movimento, sem acrescentar uma segunda auditoria.

## 3. Proteções obrigatórias

```sql
-- Esperado: exceção "A movimentação deixaria o estoque negativo."
select * from public.create_inventory_movement(
  :'item_id'::uuid,
  'INTERNAL_CONSUMPTION'::public.inventory_movement_type,
  -999.000,
  null,
  null,
  gen_random_uuid(),
  :'actor_id'::uuid
);

-- Esperado: exceção "Informe o motivo da perda ou do ajuste."
select * from public.create_inventory_movement(
  :'item_id'::uuid,
  'LOSS'::public.inventory_movement_type,
  -0.001,
  null,
  null,
  gen_random_uuid(),
  :'actor_id'::uuid
);
```

Todo dado temporário criado para verificação futura deverá ser removido somente por movimento de compensação auditável, nunca por exclusão física.
